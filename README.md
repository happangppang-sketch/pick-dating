# Pick. — 로직이 보이는 소개팅 앱

> **왜 이 사람인지 보여주는 소개팅.**
> 거르기 → 점수 → 이유, 추천 로직을 화면에 그대로 보여줍니다.

설치 없이 `index.html` 하나로 동작합니다. GitHub Pages로 바로 배포할 수 있어요.

**빠르게 둘러보기:** 첫 화면의 **"체험 계정으로 둘러보기"**를 누르세요. 아이디는 `demo`, 비밀번호는 `demo1234`입니다.

## 주요 기능

| 화면 | 내용 | 참고한 앱 |
|---|---|---|
| **회원가입** | 6단계 온보딩: 계정 → 기본 정보 → 나에 대해 → 관심사 → 사진·소개 → 이상형 조건. 비밀번호는 SHA-256 해시로 저장 | 국내 소개팅 앱 가입 흐름 |
| **홈 · 오늘의 추천** | 오늘의 1위 카드, "왜 이 사람이 1위인가?" 자동 설명, 항목별 점수 막대, 다음 소개까지 카운트다운 | 정오의 데이트 (매일 소개) |
| **탐색** | 카드 스와이프(좋아요 / 패스 / 슈퍼 좋아요 / 되돌리기), 사진 넘기기, 매칭 점수 배지 | 틴더 |
| **프로필 상세** | 질문 카드(프롬프트)에 답변, 특정 답변에 좋아요 보내기, 인증 배지, 접속 중 표시 | 힌지 · 글램 |
| **매칭** | 서로 좋아요를 누르면 "매칭 성공" 화면이 뜨고 채팅이 열림 | 틴더 |
| **좋아요** | 받은 좋아요(누르면 바로 매칭)와 보낸 좋아요 | 틴더 · 범블 |
| **채팅** | 새 매칭 목록, 대화 목록, 안 읽은 메시지 배지, 대화 시작 문장 추천, 입력 중 표시, 매칭 해제 | 힌지 |
| **마이** | 프로필 완성도, 프로필 수정, 이상형 조건, 로그아웃, 회원 탈퇴 | 글램 |
| **로직 설정** | 점수 비중 슬라이더(합계 자동 100점), 프리셋(대화·취향 / 가치관 / 첫인상 / 모두 같게), 거르기 켜고 끄기, 저장 전 1위 미리보기, 기본값 복원 | 직접 설계 |
| **내 로직** | 거르기·점수·이유 규칙과 근거, 제외된 사람과 제외된 이유 | 과제 요구사항 |

- **가상 프로필 30명** (여 15, 남 15). 항목: 나이, 키, 외모(스타일), 연봉, 종교, 관심사, 직업, 지역(서울특별시·경기도 등 시·도 단위), 소개, 질문 카드
- **사진 업로드** (최대 3장, 4:5 자동 크롭). 사진이 없으면 일러스트 아바타를 씁니다
- **같은 브라우저에서 가입한 다른 회원**도 추천에 나오고, 서로 좋아요를 누르면 실제로 매칭·채팅됩니다

## 내 로직

### ① 거르기 — 절대 안 되는 조건 (하나라도 걸리면 제외)

| 조건 | 규칙 | 이유 |
|---|---|---|
| 성별 | 원하는 성별이 아니면 제외 | 애초에 추천 대상이 아님 |
| 나이 | 허용 범위 밖이면 제외 | 생활 단계 차이는 점수로 메꿀 수 없음 |
| 키 | 허용 범위 밖이면 제외 | 본인이 정한 선은 존중 |
| 종교 | "절대 안 됨"으로 고른 종교면 제외 | 타협할 수 없는 가치관 |
| 연봉 | 최소 연봉 미만이면 제외 (기본값 0 = 안 봄) | 연봉으로 사람을 자르지 않는 쪽을 기본으로 |
| 관심사 | 겹치는 관심사가 0개면 제외 (선택) | 공통점이 없으면 첫 대화가 어려움 |

### ② 점수 — 100점 만점

| 항목 | 배점 | 규칙 | 이유 |
|---|---|---|---|
| 관심사 | **35** | 1개 겹치면 12점, 2개 24점, 3개 이상 35점 | 대화와 데이트가 이어지는 핵심이라 비중이 가장 큼 |
| 종교 | 15 | 같으면 15점 | 가치관 문제. "절대 안 됨"은 이미 거르기에서 처리함 |
| 나이 | 15 | 차이 0~2살 15점, 3~4살 8점, 5살 이상 3점 | 생활 단계와 대화 코드가 비슷함 |
| 외모 | 15 | 선호 스타일이면 15점 | 취향일 뿐이라 관심사보다 낮게 둠. 등급이 아니라 "스타일"로 기록 |
| 키 | 10 | 이상형 키와 ±3cm면 10점, ±7cm면 5점 | 허용 범위 안에서 이상형에 가까울수록 가산 |
| 연봉 | 10 | (상대 연봉 ÷ 희망 연봉) × 10, 최대 10점 | 고려는 하되 줄 세우지 않도록 비중을 가장 낮게 하고 상한을 둠 |

동점이면 겹치는 관심사가 많은 순, 그다음 나이 차가 적은 순으로 정합니다.

> **위 배점은 기본값입니다.** 마이 → **로직 설정**에서 사용자가 항목별 비중을 직접 바꿀 수 있어요.
> - 비중은 0~50 사이로 정하고, 합계가 100점이 되도록 자동으로 환산됩니다.
>   - 예: 관심사 50, 나머지 각 10이면 관심사가 50점, 나머지는 각 10점이 됩니다.
>   - 0으로 두면 그 항목은 채점하지 않습니다.
> - 거르기(나이, 키, 종교, 최소 연봉, 관심사 0개)도 하나씩 켜고 끌 수 있습니다. 성별은 항상 적용됩니다.
> - 저장하기 전에 "이 설정이면 1위가 누가 되는지"를 미리 볼 수 있고, 언제든 기본값으로 되돌릴 수 있습니다.

### ③ 이유 — 왜 이 사람이 1위인가?

1위 카드에 다음 세 가지가 자동으로 나옵니다.
- 만점 비율이 높은 항목 상위 3개
- 2위와의 점수 차이, 그리고 가장 크게 앞선 항목
- 만점이 아닌 항목 (아쉬운 점도 숨기지 않음)

**설계 원칙:** 대화가 이어질 수 있는가(관심사) > 가치관(종교·나이) > 첫인상(외모·키) > 조건(연봉)

### 💞 매칭은 어떻게 되나요?

가상 프로필도 "나를 좋아할지"를 정하는 간단한 점수를 가집니다.

`겹치는 관심사 × 15 (최대 45) + 나이 차 3살 이내 20점 / 5살 이내 10점 + 같은 종교 10점 + 그 사람만의 성향 0~29점`

- 60점 이상이면 내 좋아요에 응답해 매칭됩니다. 슈퍼 좋아요는 45점 이상이면 매칭됩니다.
- 65점 이상이면 상대가 나에게 먼저 좋아요를 보냅니다.

## 실행 · 배포

- **로컬에서 실행:** `index.html`을 브라우저로 열면 됩니다.
- **GitHub Pages로 배포:** 저장소의 Settings → Pages에서 Branch를 `main` / `(root)`로 정하고 Save를 누르면 `https://<아이디>.github.io/<저장소명>/` 주소가 생깁니다.

> 과제용 데모입니다. 계정, 사진, 대화는 서버 없이 브라우저(localStorage)에만 저장됩니다. 일러스트 아바타는 [DiceBear](https://www.dicebear.com/)의 Lorelei 스타일(CC0)을 사용했습니다.
